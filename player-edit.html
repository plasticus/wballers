Player Editor

Pick a player, tweak their face, then click Save to players.json. Locally this needs the wballers editor server (python3 player_edit_server.py on port 8001). On a PHP host it uses save.php to write the file directly.

The save button auto-detects whether it’s running locally or on a PHP host and posts to the right endpoint.
